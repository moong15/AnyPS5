## Build/deploy rule (learned the hard way, 2026-10-14)
- `cmake --build build --parallel` does NOT rebuild the game's .prx files. Always run
  `cmake --build build --target libs --parallel`, then relink + copy build/core/libs/libs/*.prx to E:\StellarBlade\libs.
- Verify a deploy: timestamp of build/core/libs/libs/libSceAgcDriver.prx is new, and a new log string is in it
  (`grep -c "<string>" build/core/libs/libs/libSceAgcDriver.prx`).
- Launch the game from a Terminal-panel tab (run_in_terminal), not a Bash background task: a session restart kills Bash children.
