# Stellar Blade / AnyPS5 change ledger

One row per change we carry or tried. Updated when a change is merged into a test or game build, and again when its A/B run is done. Source of truth for "which changes helped". Details live in stellarblade-progress.md (search the commit or switch).

## Rules
- Every change ships with an off switch (APS5_NO_...) or is opt-in. A/B = same build, switch on vs off, same scene. Cross-build comparisons are confounded by main merges and only count as weak evidence.
- Scenes: compare like windows (menu, loading, early gameplay = first 30 s after load, playable area). Align runs by the load start, not by wall time.
- Verdict values: HELPED (measured gain or fixes a crash), NEUTRAL (measured, no gain), WORSE, BROKE (caused a failure), UNMEASURED, DIAG (diagnostics only).
- Status values: UPSTREAM (merged in main), OUR PR (open, number), OTHER PR (someone else's open PR we carry), LOCAL (only on our branches), REVERTED, DROPPED.
- When main gets merged: changes that became UPSTREAM move to status UPSTREAM and leave our diff; re-run the key A/Bs only if the merge touched their files.
